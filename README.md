# paraguaynext.com (preview, wireframe v2)

English funnel site for expats moving to and living in Paraguay. ParaguayNext is an information hub and community, **not an immigration agency**.

**Status: PREVIEW ONLY.** Every page is `noindex, nofollow`, `robots.txt` disallows everything, and `site/.htaccess` sends `X-Robots-Tag: noindex, nofollow` on Apache/LiteSpeed. No analytics, no tag manager, no JavaScript, no external requests (fonts are self-hosted). The only outbound link is the primary CTA.

## Stack
Plain static HTML + one CSS file, generated by a small Python 3 script (standard library only, no dependencies). `site/` is the web root: upload its contents as-is to any static host (Hostinger `public_html`). Nothing to install, no build server needed.

```
build/build.py   # generates the 8 pages into site/ (edit this, not the HTML)
build/check.py   # preview checks: noindex, robots.txt, no scripts/forms, no external refs, local links resolve, CTA on every page, brand files byte-identical to the locked originals
site/            # web root (HTML, assets/, robots.txt, .htaccess)
docs/screenshots # evidence at 1280 and 390 px
```

Build and check:
```
python3 build/build.py && python3 build/check.py
python3 -m http.server -d site 8080   # preview at http://localhost:8080/
```

## Brand
`site/assets/brand/` holds byte-for-byte copies of the locked Logo B ("Lapacho Forward") files (`lockup/`, `symbol/`, `favicon/`, `pattern/`, `avatar/`, plus the kit README as `LOGO-README.md`). **Never edit, re-export, recolor or optimize these files**; replace them only by copying new locked originals. Colors and fonts follow the brand kit spec (yerba #1F4E36, lapacho pink #D2386C for graphics only, cream #FAF4EA, ink #1E1A17, red earth #B4442A for links; DM Serif Display + DM Sans).

## Placeholders
Everything tagged `[COPY]`, `[IMAGE]`, `[LINK]`, `[TBD]`, `[TAG]`, `[SOURCE]` or `[LEGAL]` (dashed outline) is a placeholder. Copy comes later from Sales Bot, Roger signs off. The email signup is a disabled input, not a form; nothing is collected.
